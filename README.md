## 📌 Sobre o projeto

Este repositório contém o site institucional da **FL Conecta Digital**, projeto voltado ao desenvolvimento de soluções digitais para empresas, profissionais e negócios locais.

A página apresenta serviços, benefícios, processo de atendimento, perguntas frequentes e um fluxo de diagnóstico que direciona o visitante para atendimento pelo WhatsApp.

## ✨ Principais recursos

- 💻 Apresentação de serviços de criação de sites
- 🚀 Landing pages para captação de clientes
- ⚙️ Sistemas web personalizados
- 📱 Layout responsivo
- 💬 Integração direta com WhatsApp
- 📝 Formulário de diagnóstico com validação
- 💾 Registro local dos dados do formulário no navegador
- ❓ Seção de perguntas frequentes
- 🎬 Animações de entrada com IntersectionObserver
- ♿ Suporte a prefers-reduced-motion
- 📣 Integração com divulgação regional

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- WhatsApp URL API
- Git e GitHub
- Publicação via cPanel

## ▶️ Como executar

Por ser um projeto estático, você pode abrir o `index.html` diretamente no navegador.

Para desenvolvimento local, também pode usar uma extensão como **Live Server** no VS Code.

## 🎯 Objetivo

A FL Conecta Digital busca ajudar negócios a construir presença profissional na internet e gerar contatos através de sites, páginas de conversão, sistemas e integrações digitais.

Este projeto também faz parte do meu portfólio prático de **Desenvolvimento Web**.
